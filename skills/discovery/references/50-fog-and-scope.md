# Fog and Scope

## Not Yet Specified

`Not yet specified` contains in-scope fog: future decisions or investigations that are visible but cannot yet be expressed as a precise Question.

The test is precision, not answerability:

- Create a ticket when the Question can be stated clearly now, even if another ticket blocks it.
- Keep an item in fog when the Question itself still depends on unresolved knowledge.

Do not pre-slice vague fog into speculative tickets.

When a resolution makes a fog item precise, create the appropriate child ticket and remove the graduated text from `Not yet specified`.

## Decisions So Far

This section contains resolved route decisions only.

Exclude:

- open tickets;
- fog;
- research still in flight;
- scope exclusions.

## Out of Scope

`Out of scope` contains work consciously excluded by the Destination.

Out-of-scope work never graduates unless the Destination is explicitly redrawn.

If an existing ticket is discovered to sit beyond the Destination:

1. preview the scope ruling;
2. close the ticket after approval;
3. add a linked title, brief gist, and reason under `Out of scope`;
4. do not add it to `Decisions so far`.
