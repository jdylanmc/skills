# Error Handling

- **Missing tracker, domain, or triage guidance:** Stop and direct the user to `/setup-jdylanmc-skills`.
- **Ambiguous source:** Ask which artifact to break down.
- **Understanding insufficient:** Explore narrowly; if still unclear, state the unknown rather than slicing blindly.
- **Horizontal ticket detected:** Reslice vertically before preview.
- **Cycle in blockers:** Remove or redesign edges before publication.
- **Approval withheld:** Make no write and retain the preview.
- **Duplicate graph:** Offer to resume or add missing items rather than duplicating it.
- **Partial publication:** Requery and create only missing tickets and relations.
- **Relation failure:** Apply the configured fallback or stop.
- **Concurrent change:** Abort stale writes, reload, and report.
- **Source mutation detected:** Stop and report the unexpected change.
- **Execution requested:** Decline; this skill publishes the graph only.
