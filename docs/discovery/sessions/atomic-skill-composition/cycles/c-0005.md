## Decisions

1. **Unit names are `<domain>-<verb>[-<object>].md`** - kebab-case, globally
   unique, no numeric prefix, **no level suffix**. Domain first, so families
   cluster alphabetically in a flat namespace.
2. **Level namespaces stay flat**, revisited only when one domain prefix exceeds
   roughly twenty units.
3. **Every unit declares `## Inputs`, `## Output`, `## Guarantees`, and
   `## Boundaries`.** Without a declared contract a caller must read the whole
   file to compose it.
4. **A `## Required References` section contains its list and nothing else**, and
   sits immediately before the next `##` heading.
5. **Collapse takes the union**, then decides per requirement whether it belongs
   to the unit or to the caller.
6. **Every adversarial review is given a mandate to execute**, with a reproducing
   command and its output attached to each finding.

The user's proposed `<purpose>.atom.md` suffix was declined on executed
evidence, not preference: `validate-skill-graph.mjs` line 304 requires
frontmatter `name` to equal the file stem, forcing `name: <purpose>.atom`, and
line 87's `unitNameOf` takes the first dot-separated segment, so any unit with a
support file would fail the build at line 115.

## The Main Finding: Collapse Loses the Strictest Copy

Seven regressions were found - two by the loop's own audit of removed prose,
five by an adversarial review. **Five of the seven were the same class.**

| Regression | Lost requirement | Fixed in |
| --- | --- | --- |
| Validation only after writing | Stage and validate before replacing | unit |
| Architecture scope rule | Documenting is not approval to write | caller |
| Diff passed as `content` | Preview may diff; payload is the whole document | both |
| Timeout not retried | Retry once before declaring unavailable | unit |
| Identity echo weakened | Must match, in `Skill Summary` and every finding | unit |

**When N copies of a behavior differ, the union of their requirements is larger
than any single copy.** Collapsing to the most common wording drops whichever
copy was strictest - and the strictest copy is usually strictest because someone
hit the failure it prevents.

Collapse is therefore three steps, not a move: take the union; decide per
requirement whether it belongs to the unit or the caller; audit the removed text
against unit plus caller before merge. Step 3 is the strongest answer yet to
n-0005's "what check proves collapse", and it is currently a **human diff
review**. No claim is made that it is automatable.
