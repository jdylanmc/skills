## Decisions

1. Address is the sole authority for composition level. A unit exists only
   inside a level namespace; a file outside one is not a unit and carries no
   level.
2. The endpoint is total migration. Every reference file eventually becomes a
   unit under `skills/_base/`. No skill remains unclassified.
3. `SKILL.md` is a thin wrapper. Substance lives in the units it composes.
4. Migration order is value-first, superseding the simplest-first ordering the
   user gave alongside the Q1 answer.
5. Granularity is an empirical parameter, measured rather than declared.
6. The first target is `roast-this-prompt`, with both siblings in scope.
7. A referenced unit is incorporated by prose instruction plus relative link.
   Runtime places no constraint on where a unit lives.
