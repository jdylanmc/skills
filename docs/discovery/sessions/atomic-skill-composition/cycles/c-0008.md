## Decisions

1. Handoff is a bounded continuation artifact, not a transcript, memory
   system, tracker, or general persistence framework.
2. It writes only under the runtime-reported operating-system temporary
   directory.
3. It references existing artifacts instead of duplicating them.
4. It redacts secrets, credentials, and personally identifiable information.
5. Arguments tailor the next session's focus.
6. Agents and orchestrators must be able to invoke or compose the capability
   explicitly.
